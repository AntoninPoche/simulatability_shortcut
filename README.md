This repo was created from [contrastive_concepts](https://github.com/AntoninPoche/contrastive_concepts)
because, the simulatability experiments did not allow to differentiate between explanations methods and the no-explanation baseline.

This repo thus will serve for experiments to raise awareness on the weaknesses of automated simulatability.

There will be experiments first to show that the new ConSim is better than the old ConSim. (The difference is asking for answers one by one or all at the same time).

Then there will be rationales, attributions, and concepts simulatability experiments.

We should have several datasets, LLM judges, types of explanations and methods in each type of explanations.
